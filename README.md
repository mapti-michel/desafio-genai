# Desafio-genai

OBS.: Este desafio refere-se ao bootcamp Bradesco, sobre Dados, Cybersecurity e Genai

Atue como analista de dados ou analista de experiência do cliente.

Sua tarefa é analisar feedbacks de clientes de um aplicativo bancário sobre serviço de pix para identificar a facilidade de uso.

CONTEXTO: A análise será usada por uma equipe de clientes para priorizar o uso de melhorias do serviço de pix.

DADOS DISPONÍVEIS: A base contém data do comentário, canal do atendimento, texto do feedback, produto e nota de satisfação do cliente.

INSTRUÇÕES PARA ANÁLISE:
  Classifique os feedbacks por sentimento, urgência, canal, produto ou outro critério.
  Identifique os principais padrões, problemas, elogios e oportunidades.
  Aponte evidências nos dados fornecidos.
  Sugira ações práticas para a equipe de experiência do cliente.
  Formato da resposta: Entregue um resumo executivo  com até 15 linhas, em uma tabela com tema, sentimento, evidência e ação sugerida, além de uma lista final com as 5 prioridades importantes.

RESTRIÇÕES:
  Use apenas os dados fornecidos.
  Não invente números, causas ou conclusões.
  Não exponha dados pessoais ou sensíveis.
  Informe limitações quando os dados não forem suficientes.
  Use linguagem simples.
